# v1.3 重点改进说明

## 统一任务中心

主界面进入“统一任务中心”后，可以查看全部任务的编号、类型、状态、完成数量和失败原因，并执行暂停、继续、取消和失败重试。任务元数据保存在：

```text
09_周期汇总/任务状态.json
```

程序重新启动后，可以从该文件识别未完成任务。

## OCR 质量复核

扫描 PDF 处理结果增加：

- 总页数；
- 每页字符数；
- 中文字符数；
- 异常字符提示；
- 是否需要人工复核。

OCR 质量提示是风险提示，不替代人工对照原图。

## 安全密钥存储

Windows EXE 优先使用当前用户 DPAPI 保存密钥，密钥文件位于程序目录下的 `.secrets`，已经加入 Git 忽略规则。也可以继续使用环境变量：

```powershell
$env:WESTGAS_DEEPSEEK_API_KEY = "你的密钥"
$env:WESTGAS_DOUBAO_API_KEY = "你的密钥"
```

环境变量优先级最高，其次是 DPAPI，再次才是旧版 `config.json` 明文配置兼容读取。

## 混合检索

混合检索同时计算：

- 关键词命中分数；
- 本地字符片段语义相似度；
- 领域和属性过滤结果。

检索结果显示综合得分、命中方式和原文证据。当前实现无需联网，后续可以替换为本地 Embedding 向量索引。

## 问题归并人工确认

系统只生成归并建议，不直接修改原台账：

```text
生成建议 → 人工同意/不同意 → 应用已同意归并 → 生成 11_重复与冲突/归并结果_*.md
```

归并审核记录保存在：

```text
09_周期汇总/问题归并审核.json
```
