# v1.2 改进说明

## 1. 批量任务

批量处理会生成唯一任务编号，例如 `TASK-20261001013000-AB12CD`。任务状态包括：

`queued`、`running`、`paused`、`cancelled`、`failed`、`completed`。

任务状态保存在知识库的 `09_周期汇总/任务状态.json`。程序异常退出后，可读取状态文件恢复未完成任务；失败任务可以重新排队。原始资料不会因暂停、取消或重试而被覆盖。

## 2. AI、规则版和 OCR

调用明细保存在 `00_系统说明/AI调用日志.jsonl`，包括：

- 工具名称和处理环节；
- 成功或失败；
- 调用耗时；
- 提示词版本和规则版本；
- 失败原因。

扫描 PDF 会返回 OCR 质量等级。出现文字过少、无法识别字符或中文比例偏低时，界面提示人工对照原图复核。

## 3. 配置和密钥

保存配置前会检查知识库目录、默认工具、AI 工具和接口地址。API Key 推荐使用环境变量：

```powershell
$env:WESTGAS_DEEPSEEK_API_KEY = "你的密钥"
$env:WESTGAS_DOUBAO_API_KEY = "你的密钥"
```

环境变量优先于 `config.json`，日志不会记录密钥。

## 4. 检索和治理

- 检索结果显示原文证据片段；
- 可按领域、属性筛选；
- 可传入同义词扩展关键词；
- 支持问题趋势统计；
- 支持轻量语义相似检索；
- 支持查看相关文档；
- 支持生成专题报告。

SQLite 的 `schema_version` 用于迁移数据库结构。Markdown 仍是知识正文和 Obsidian 主数据源，索引可以删除后重建。

## 5. 规则持续改进

人工确认后的分类修正写入 `09_周期汇总/规则版反馈.jsonl`。调用 `ai_tools.rule_improvement_report()` 可查看高频修正方向。系统不会未经人工批准自动改变全局规则。
