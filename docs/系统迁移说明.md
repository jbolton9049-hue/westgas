# 系统迁移说明

## 迁移包包含内容

系统迁移包会包含：

- `01_原始资料库` 至 `12_失效资料` 中的知识文件；
- 记忆卡片和训练记录；
- 任务状态和规则版反馈；
- SQLite 索引之外的 Markdown 主数据；
- 脱敏后的配置模板；
- 文件清单和 SHA-256 校验值。

系统迁移包不会包含：

- API Key；
- `.secrets` 目录；
- SQLite 临时文件；
- 备份目录中的旧 ZIP；
- 构建缓存。

## 使用步骤

### 旧电脑

1. 打开“系统设置”。
2. 点击“创建系统迁移包”。
3. 选择保存位置。
4. 将生成的 ZIP 文件复制到新电脑。

### 新电脑

1. 启动新版本程序。
2. 打开“系统设置”。
3. 点击“恢复系统迁移包”。
4. 选择 ZIP 文件和目标知识库目录。
5. 确认恢复。
6. 重新配置 DeepSeek 或豆包 API Key。

恢复前程序会自动创建目标目录安全备份。恢复完成后，SQLite 索引可以自动重新建立。

## 安全规则

- 迁移包中的 API Key 始终为空；
- 发现 `.secret` 或 `.secrets` 文件时拒绝恢复；
- 发现 ZIP 路径穿越时拒绝恢复；
- 任一文件 SHA-256 校验失败时停止恢复；
- 原始迁移包不会被修改。
